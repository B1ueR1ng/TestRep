# TestRep
여러가지 테스트 릴리즈 노트용 레포 [KeycapRogue]

모든 테스트 파일 다운로드는 우측의 릴리즈 (Releases) 에서 확인 가능합니다.

가장 최신은 Latest, Latest 릴리즈 내에서는 가장 큰 번호가 가장 최신입니다.

다운로드는 zip 파일 한 개만 다운로드 받아서 진행하면 됩니다.
